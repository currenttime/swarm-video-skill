# 制作过程

1. 读取输入视频的有效画面时长、时间戳和显示比例。成片模式默认原速播放，工作区录屏模式默认 5 倍速。两种方式均默认静音，输出 60fps。
2. 成片模式读取静态 PNG 工作区和两处标定矩形。把输入画面等比放进播放器，并将同一视频制成时间线缩略图。录屏模式以真实录屏为底层，按抽帧定位要修改的时间线。
3. 把光标与反馈映射到各面板。左上素材卡片高亮、左下工具和节点短暂点亮，右侧参数曲线和播放器下方控制区有联动反馈。把若干次操作编成「选素材 → 点工具 → 时间线落片段」的接力。时间线另有 132 次点击，关联 268 个示意片段、音频波形和动效元素。各片段在对应动画光标点击之后出现。
4. 用 Remotion 逐帧渲染透明动效，再用 FFmpeg 与底层视频合成。流程逐帧检查光标和动效的空间范围，完整解码并抽查播放器和其他面板。成片模式还比较实际播放器画面和准备好的视频、静态模板画面。
5. 保留模板、播放器视频、缩略图和项目规则。编辑行为、光标、波形和轨道参数描述的是演示动画。

## 重新导出可编辑工程

修改输出目录下的 `project/src/workbench-data.json` 或 `project/src/Workbench.tsx` 后，在 `project/` 执行 `npm run render` 生成透明帧。若仅替换静态外观，可直接用尺寸一致、区域相同的图覆盖生成工程的 `project/public/workspace.png`。

```bash
python /path/to/swarm-video-skill/scripts/reexport.py /path/to/output-folder
```

重新合成会生成 `swarm-video-edited.mp4`。改变播放器矩形或尺寸时应从原视频重新生成，以便重新适配播放器视频。
